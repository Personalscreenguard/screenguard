屏幕多了，控制不必更复杂。

一台主屏加一块副屏，或是横竖屏组合，常用的显示控制集中在一个地方。

Screenguard 是一款面向多屏桌面的显示器控制和窗口助手。它通过系统接口与显示器 DDC/CI 控制常见操作，不把基础使用建立在额外控制软件上。每项能力仍取决于操作系统、显示器和连接方式，界面会明确提示支持情况。

01 / LOCAL

本机完成日常控制

主要显示与窗口操作在电脑本地执行；无需账户，也不依赖云端服务。

02 / CLEAR

能力与限制说清楚

DDC/CI 支持受显示器和转接链路影响；不支持或无法回读时，界面会如实说明。

03 / INCLUDED

核心功能随应用提供

显示器控制无需另装 BetterDisplay 或其他显示器控制软件。

GOOD TO KNOW

下载前，先了解这几件事。

安装和屏幕兼容问题，通常从这里就能找到方向。

需要再安装 BetterDisplay 吗？

不需要。Screenguard 的核心显示器控制不依赖 BetterDisplay。macOS 安装包会附带所需的开源布局组件。

为什么有些亮度或电源按钮不可用？

这些控制依赖显示器支持 DDC/CI，且连接链路能够传递对应信号。某些扩展坞、切换器、转接线或电视会限制读取或写入。

macOS 或 Windows 出现安全提示怎么办？

桌面包采用未签名分发。macOS 可能提示无法验证开发者；Windows 可能显示未知发布者或 SmartScreen 提示。请只从本页链接的官方 GitHub Releases 下载。

会控制显示器的实体电源吗？

应用发送待机或唤醒请求，部分显示器会进入待机状态，但软件不能保证所有型号都能被控制，也不等同于切断物理供电。
