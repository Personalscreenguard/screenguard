🔋 电池设备

正在读取带电池的设备…
覆盖笔记本内电池、USB / 2.4G 无线键鼠、蓝牙耳机等所有带电池的设备，显示电量、充电状态、健康度（满充容量 ÷ 设计容量）与耗电曲线。注意：若开着电池保养模式（限充 80%），健康度会显示约 80%，属正常，不是损耗；部分外设（如 ROG OMNI 接收器）走厂商私有协议，Windows 标准接口读不到电量，只有厂商软件（Armoury Crate）能看到。

🎨 色彩同步

让多块屏幕色彩一致 / 对齐标准
标准目标色彩空间不等于显示器硬件校色；深度校准仍需校色仪及显示器专属配置。
⚠️ HDR 按钮是「读取并显示当前状态」（开 / 关 / 混合）。本机实测：切换指令能发出，但系统拒绝 Apply（错误 87），HDR 被厂商服务 AsHDRControl 接管 —— 所以点它不会真的改变 HDR，要改请用「设置 → 系统 → 显示 → HDR」或华硕工具。「色彩空间」若和目标本来就一致（例如两块屏都是 sRGB），也不会有视觉变化，这是正常的。

🪟 窗口 / 多屏布局

把副屏的缩放档改成与主屏一致（原值自动备份，可一键还原）。为什么以前"看着没实现"：Windows 改每屏缩放只有注册表一条路、且必须注销或重新登录才生效，没有运行时 API 能立刻变 —— 这是系统限制。点完按钮重启登录即可看到效果。

📐 双屏对齐体检

先体检，再由你确认是否应用分辨率组合 
两块屏跨屏拼画面要对得齐，唯一的条件是「竖向像素高度 ≈ 与各自物理高度成正比」（即竖向像素密度一致）。点「开始体检」会读取每块屏的物理尺寸、当前分辨率、全部可用分辨率，算出：谁会被切掉多少画面、PPI 差多少、哪些分辨率组合能对上、以及推荐方案。

🎬 双屏铺满

任意窗口横跨两块屏
推荐：点「刷新窗口列表」→ 在「目标窗口」里选中 → 点「铺满选中窗口」。任意已打开的应用窗口都能铺满，无需安装播放器。铺满后点「还原」即可回到原位置；Windows 也可按 Ctrl+Alt+R。macOS 需要允许 Screenguard 使用「辅助功能」调整窗口；如窗口标题显示为未命名，可在「屏幕与系统音频录制」中授权以读取完整窗口信息。不同屏幕的边框仍是物理间隔，跨屏画面只能按两屏布局延展。

🛟 一键恢复默认

把「软件层面」的改动全部还原
覆盖范围：总亮度（回到原始曲线）、色彩配置、被铺满的窗口、屏幕电源、音量 —— 全部回到软件启动时的状态（启动时会自动存一份「基线」，所以乱调之后总能一键回到好的状态）。硬件层面的设置不受影响（显示器自己的亮度/音量、KVM 都不动）。

应用会定期检查公开版本；不会自动下载或安装。未签名分发下，更新由用户确认后从 GitHub 下载。

🗂️ 设置备份

只导入导出应用偏好
备份包含应用偏好，可能含本地 IP 或设备标识；不包含恢复基线、日志、密码或令牌。只在你信任的位置保存备份文件。
