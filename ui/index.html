🔋 电池设备

正在读取带电池的设备…
覆盖笔记本内电池、USB / 2.4G 无线键鼠、蓝牙耳机等所有带电池的设备，显示电量、充电状态、健康度（满充容量 ÷ 设计容量）与耗电曲线。注意：若开着电池保养模式（限充 80%），健康度会显示约 80%，属正常，不是损耗；部分外设（如 ROG OMNI 接收器）走厂商私有协议，Windows 标准接口读不到电量，只有厂商软件（Armoury Crate）能看到。

🎨 色彩同步

让多块屏幕色彩一致 / 对齐标准
支持 8 种目标色彩空间（sRGB / P3 / Adobe RGB / DCI-P3 / Rec.709 / Rec.2020 / ProPhoto / 灰度）｜Windows 只自带 sRGB，其它需把 .icc 放进 %LOCALAPPDATA%\screenguard_icc\（软按文件名自动识别，不限这三种）｜深度校准仍需硬件校色仪（DisplayCAL）

🪟 窗口 / 多屏布局

把副屏的缩放档改成与主屏一致（原值自动备份，可一键还原）。为什么以前"看着没实现"：Windows 改每屏缩放只有注册表一条路、且必须注销或重新登录才生效，没有运行时 API 能立刻变 —— 这是系统限制。点完按钮重启登录即可看到效果。

🎬 双屏铺满

任意窗口横跨两块屏
推荐：点「刷新窗口列表」→ 在「目标窗口」里选中 → 点「铺满选中窗口」。任何窗口都能铺满（浏览器里的抖音全屏、PotPlayer、VLC…）。铺满后若界面被盖住，按 Ctrl+Alt+R 或右键托盘「还原铺满的窗口」即可还原 —— 不会再有「点不到按钮」的情况。

🛟 一键恢复默认

把「软件层面」的改动全部还原
覆盖范围：总亮度（回到原始曲线）、HDR、色彩配置、被铺满的窗口、屏幕电源、音量 —— 全部回到软件启动时的状态（启动时会自动存一份「基线」，所以乱调之后总能一键回到好的状态）。硬件层面的设置不受影响（显示器自己的亮度/音量、KVM 都不动）。
